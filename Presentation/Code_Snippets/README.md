## How to Use

### In PowerPoint:

1. **Insert Code Block:**
   - Insert → Text Box
   - Paste code snippet
   - Format with monospace font (Consolas, Courier New)

2. **Syntax Highlighting:**
   - Copy from VS Code (preserves colors)
   - Or use PowerPoint's built-in code formatting
   - Or manually color keywords

3. **Best Practices:**
   - Keep snippets short (10-15 lines max)
   - Add comments to explain key parts
   - Highlight important lines with background color
   - Include file path reference

### Recommended Formatting:

```
Font: Consolas or Courier New
Size: 10-12pt
Line Spacing: 1.15
Background: Light gray (#F5F5F5)
Border: 1pt solid gray
```

### Color Scheme (Python):

- **Keywords:** Blue (#0000FF)
- **Strings:** Green (#008000)
- **Comments:** Gray (#808080)
- **Functions:** Purple (#800080)
- **Decorators:** Orange (#FF8000)

## Tips for Code in Slides

1. **Don't Show Everything:**
   - Focus on key functionality
   - Use "..." to indicate omitted code
   - Show only relevant parts

2. **Add Annotations:**
   - Use arrows to point to important lines
   - Add text boxes with explanations
   - Highlight with colored backgrounds

3. **Progressive Disclosure:**
   - Animate code appearing line-by-line
   - Build up complex functions step by step
   - Show before/after comparisons

4. **Context Matters:**
   - Always include file path
   - Show line numbers
   - Explain what the code does
